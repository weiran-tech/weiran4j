# 研发交接与验收参考

> 当前版本由 AI 维护源码，网页仅记录本机评审，见[版本管理](./versions.md)。下文涉及旧 Discussion、候选、交接和批准的步骤仅作历史兼容参考，不是当前网页操作流程。
版本页面保留“原型与改动”和“评审与结论”，不再提供研发交接摘要、任务矩阵、验收表单或上线复核操作。

定稿后，从版本详情打开固定原型，通过改动说明抽屉查看业务规则和验收条件。研发任务、实现 PR、测试环境、验收证据及发布记录在团队使用的任务系统和 GitHub 中维护，并关联版本及 CHG 编号。

历史交接记录、本人确认和归档门禁继续保留；网页不会自动补造验收、批准或发布事实。
