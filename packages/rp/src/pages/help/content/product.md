# 使用 AI 制作与演示原型

先明确目标版本和基线，再让 AI 维护 `prototype/versions/<版本>/version.json` 及对应页面的 `changes/<pageId>.json`。必须存在唯一进行中版本，才能调整页面、规则、文案与 Mock；网页不创建或编辑版本。

向 AI 说明适用端、页面、原有行为、期望行为、业务规则和异常场景。新增页面先登记稳定编号；共享组件或 Mock 调整也要关联受影响页面的本版 CHG。具体约束见[版本管理](./versions.md)。

管理端保留 React + Semi UI，手机端保留 Vue + Vant。所有演示数据保存在当前浏览器，不连接真实业务服务。修改后运行检查、测试和构建，并在浏览器核对布局和正常、空数据、失败场景。

从版本详情选择完整产品或本版改动，按端和模块打开页面。改动说明展示调整前后、规则和验收条件；历史页面仅打开对应固定快照。进入“评审记录”填写本机意见，支持截图与导出，见[本机评审](./review.md)。
