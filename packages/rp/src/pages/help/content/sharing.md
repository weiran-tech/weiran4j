# 共享记录与多人协作

版本、页面目录和 CHG 随源码提交共享，网页不修改这些记录。修改前检查当前进行中版本和工作区，先同步已有改动，再维护对应页面的 CHG。

本机评审只保存在当前浏览器，不会自动同步到其他成员。需要移交时导出 JSON 或包含图片的 HTML，也可打印 PDF；接收方根据版本、端、页面和 CHG 复核。

产品意见、处理结论和验收证据通过团队选用的方式移交，不关联 GitHub Issue 或 Discussion。不要将本机保存成功理解为团队已收到或版本已完结。

版本完结与历史快照见[版本管理](./versions.md)，发布见[构建与部署](./deployment.md)。
