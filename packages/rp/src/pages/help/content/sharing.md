# 共享记录与多人协作

## GitHub 记录与站点摘要

交接信息和评审结论在 GitHub 主评审记录中维护，版本详情只读展示已同步摘要。GitHub 正文更新后，站点摘要和部署还需要同步；缺少摘要时以 GitHub 实时记录为准。

站内不再提供交接编辑、草稿保存、合并、导入导出或版本归档操作，既有本机数据不会自动删除。版本目标、基线和日期仍可通过“编辑版本记录”维护，改动说明随源码提交。

维护者可在受信本机环境使用 `pnpm handoff:pull -- v0.8` 获取实时记录，按仓库协作规范维护来源和冲突，再同步摘要并部署。候选与固定归档由仓库工具执行，操作见[候选与部署](./deployment.md)。

本人确认、阻塞复核及在线归档门禁继续有效，站点不会替代本人批准或自动发布。
