# 岗位与流程

当前协作围绕源码版本和本机评审开展，不需要切换网页岗位。

| 参与者 | 工作 |
| --- | --- |
| 产品 | 向 AI 说明目标、页面、业务规则与验收条件，走查原型并记录意见 |
| 开发 | 维护唯一进行中版本、页面目录、CHG、实现与 Mock，完成验证 |
| 评审者 | 在进行中版本保存本机意见和截图，导出后移交团队 |
| 版本维护者 | 实现提交后登记 implementationRef、完结版本；下一轮创建新版本 |

已完结版本只读。评审意见通过本机记录与导出文件移交，不关联远程任务或讨论。业务实现和发布由实际业务仓库安排。

操作见[版本管理](./versions.md)和[本机评审](./review.md)。
