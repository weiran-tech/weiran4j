# 从这里开始协作

本项目用于制作双端原型、管理版本、组织评审和研发验收。所有原型调整先明确目标版本与已评审定稿基线，执行 `pnpm version:work -- <版本>` 检查通过后再工作。从[版本清单](/versions)选择版本，按 **产品制作 → 组织评审 → 研发与验收** 推进。

## 进入版本后

- **原型与改动**：通过抽屉阅读规则和验收条件，在当前目录体验原型、查看本版改动。
- **评审与结论**：进入版本 Discussion，核对问题、本人确认和定稿依据。

独立版本清单 `/versions` 和详情与首页共用公共导航，不进入管理端或手机端外壳。版本详情顶部可返回清单或切换版本；管理端、手机端只用于体验原型。

版本详情只读展示 GitHub 共享记录；维护区仅提供摘要和维护指南，不提供交接编辑或版本归档操作。原型使用浏览器演示数据，不执行真实业务操作。

站内只维护版本记录，改动记录随源码提交；页面内的“改动说明 / 本页改动”按钮通过抽屉展示内容。
