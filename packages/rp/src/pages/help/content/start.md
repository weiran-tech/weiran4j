# 快速开始

从首页进入[版本清单](/versions)，选择版本查看“原型与改动”或“评审记录”。管理端和手机端保留独立演示入口，指南无需登录即可阅读。

| 工作 | 操作 |
| --- | --- |
| 制作或修改原型 | 通过 AI 登记唯一进行中版本、页面和 CHG，再修改源码 |
| 查看本次变化 | 版本详情选择“本版改动”，通过按钮打开改动说明 |
| 体验整个产品 | 选择“完整产品”，按端和模块打开页面 |
| 记录评审 | 进行中版本填写本机意见、关联页面并上传或粘贴截图 |
| 分享评审结果 | 导出 JSON 或带图片的 HTML；HTML 可打印 PDF |
| 完结版本 | 先提交实现，通过 AI 登记 implementationRef 并完结 |

本机记录只在当前浏览器，不会自动上传。已完结版本只能查看和导出，历史页面只打开固定快照。详见[版本管理](./versions.md)、[本机评审](./review.md)和[本地开发](./development.md)。
