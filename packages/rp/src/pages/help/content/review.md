# 本机评审

从版本清单进入版本详情，选择“评审记录”。进行中版本可新增、编辑意见，已完结版本仅查看和导出。

填写记录人和评审意见，选择关联端、页面及 CHG。支持上传或粘贴 PNG、JPEG、WebP 截图，每条最多 6 张，每张 1 MB。保存失败时输入会保留，可检查浏览器存储后重试。

评审仅存当前浏览器，不上传 GitHub，不批准定稿。导出 JSON 便于移交记录；导出 HTML 包含图片，可在浏览器打印 PDF。版本状态由 AI 修改源码维护，见[版本管理](./versions.md)。

页面顶部的本机备注入口及 Ctrl / Cmd + Shift + E 保留旧备注能力，支持文字、图片与按版本导出。旧本机备注和截图使用独立存储，在原入口导出；完结版本禁止新增、编辑或删除旧备注。

历史 GitHub Issue / Discussion、交接和批准材料仍在仓库中保留，固定归档继续按原地址访问。它们不再是当前网页新增评审的必经步骤，“已完结”也不代替历史真实批准。
