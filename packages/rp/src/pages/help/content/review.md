# 组织评审与记录结论

每个版本使用一个 GitHub Discussion，围绕固定候选、页面编号和 CHG 进行评审。正文保存版本目标、完整交接记录和候选地址；独立意见放在顶层评论，处理过程在同一评论串回复。

## 发起评审

1. 在 GitHub 主评审记录中维护产品、技术负责人、固定候选、团队 HTTPS 地址和演示数据；站内只读展示同步结果。
2. 新版本先保存不完整本机草稿。在“创建版本 Discussion”入口预填完整交接正文，或复制生成的正文到 Discussion。使用仓库 General 分类，每版一个主题。
3. 执行 `pnpm version:review -- v0.8 discussion:编号`，校验版本、结构化记录和打开状态，将登记保存到 `prototype/discussions.json` 并提交。新版登记优先于旧 Issue，旧链接和历史正文不删除。
4. 发起评审前生成固定候选；评审者按模块与页面走查。使用页面“复制评审上下文”将版本、CHG、场景、原型地址粘贴到版本 Discussion 评论中，避免每页新开一个主题。

## 页面截图、标注与 PDF

管理端业务页顶部、管理端内“手机端产品”预览，以及独立手机页面均提供“截图标注”。打开弹窗后可点“选择已有截图”，上传手动截取的 PNG、JPEG 或 WebP 图片（不超过 10 MB、2400 万像素），核对图片与关联页面后再标注。也可点击“截取当前页面”：管理端截取当前可见区域，手机预览截取同域手机 iframe 的可见画面。滚动到目标位置或先打开业务弹窗，再截图。

在截图上拖动框选可疑位置，系统按顺序编号；在对应意见框中填写问题、预期行为与复现步骤。也可使用“标注整张截图”通过键盘填写意见。“撤销最后标注”移除最近一框，“整体评审意见”记录页面结论。

“保存本机记录”保存原图、框选及意见，可在“本版本的本机截图记录”重开并继续编辑。同一构建最多保存 12 条，存储不足时先导出 PDF 再删除旧记录；记录仅在当前浏览器，固定候选与版本工作构建相互隔离。重新截图或关闭时，未保存修改会提示确认。

“导出标注 PDF”包含版本、基线、端、页面、CHG、场景、记录时间、截图来源、关联页面地址、编号意见及标注图片。长意见和长图自动分页，中文按画布输出。PDF 可不经过本机保存直接导出，但导出不会替代保存草稿。

两种方式均不调用系统截屏或屏幕录制权限。网页截图依赖页面已加载及同域内容，跨域图片可能缺失，可改为选择已有截图。导出后核对画面与文字，并将 PDF 手动上传到版本 Discussion 评论，附上复现说明。本机保存和 PDF 下载均不会自动提交评审或完成批准。旧固定归档保持原样；旧手机页面可从当前协作站的手机预览入口截图。

## 意见与阻塞

| 结论 | 需要记录 |
| --- | --- |
| 采用 | 原型和说明修改、复核证据 |
| 暂缓 | 原因与后续承接任务 |
| 不采用 | 原因与产品本人结论 |

普通意见在评论串明确采用、暂缓或不采用，补充原因和证据。独立缺陷或研发任务可以另建 Issue，并在评论中关联。

阻塞意见在顶层评论独立一行写 `prototype:blocker`。产品本人必须在该评论下回复：

```text
/prototype resolve v0.8 adopted
原因：说明采取的处理
证据：https://可访问的复核证据
```

`adopted` 表示采用，`rejected` 表示不采用，`deferred` 表示暂缓。暂缓还需要另起一行填写 `承接：https://后续任务`。未有有效本人结论、证据不足，或复核后原意见又被编辑，均不能通过定稿检查。隐藏评论不等于解除阻塞。

## 本人确认与定版

产品、技术在版本主评审记录中使用页面提供的完整命令本人评论，命令绑定候选编号和业务指纹。更换候选、业务页面或规则后需要重新确认。产品最终批准必须晚于全部阻塞复核。

维护者执行在线归档门禁后才形成定版快照；Discussion 标记答案或关闭讨论均不代表已定版。Discussion 顶层评论和回复均参与分页读取，使用实际作者和编辑时间核对，不代写批准。

## 历史兼容与同步

`prototype/reviews.json` 保留历史 Issue 登记。迁移前，原版本仍从该 Issue 读取交接与本人确认；迁移时先复制完整正文到 Discussion，再登记并重新确认，不自动搬迁评论或继承批准。

`pnpm handoff:pull -- 版本` 获取已登记来源的实时交接包；`pnpm handoff:prepare -- 文件` 合并最新正文。网页默认只读部署时的摘要，实时内容以 GitHub 为准。

GitHub Actions 需要 `discussions: read` 和 `issues: read`；Discussion 和评论变动会触发摘要同步。功能未启用、权限不足或读取不完整时检查失败，不使用旧记录代替。

## 在版本原型中快捷记录

在管理端或手机端原型按 **Ctrl / Cmd + Shift + E**，或点击“评审备注”按钮，呼出当前版本评审窗口。可直接记录文字，也可选择 / 粘贴 PNG、JPEG、WebP 图片（每张不超过 2 MB），保存后保留在当前浏览器。

记录不会自动提交 GitHub，也不代表评审通过。导出入口按当前版本批量生成 JSON 或含图片的 HTML，HTML 可打印 PDF。先保存当前输入再导出；浏览器存储空间不足时会提示失败，并保留窗口内内容。
