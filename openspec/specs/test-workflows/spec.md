# test-workflows Specification

## Purpose
本能力长期负责项目 API、浏览器与手工接口测试流程的登记、发现、执行、认证上下文、证据复核与恢复，使开发者能复用共享步骤、确认实际覆盖，并准确区分离线检查、合成回归与真实业务执行结果。

## Requirements

### Requirement: [FR-001] 统一流程目录与执行入口

测试工作流 **MUST** 使用根 tests/ 管理 Playwright API/E2E、Bruno 集合、共享步骤、环境与注册表，通过根 pnpm 命令执行和发现。流程声明 **MUST** 包含稳定 ID、入口、运行器、前提、清理、期望用例数和必要证据。

#### Scenario: 流程发现与声明一致
- **WHEN** 执行流程 list 和深度 check
- **THEN** 注册流程、工具发现的用例、共享步骤索引与声明数量一致，缺入口或未登记依赖会失败
- **判据**:离线回归分别制造悬空路径、额外用例和步骤索引缺失，检查退出码非 0；合法临时仓库通过。

### Requirement: [FR-002] 严格执行与证据复核

执行器 **MUST** 为每次选择生成批次摘要，为每个实际执行项生成独立运行记录及必要证据；失败、skipped、flaky、断言降级、空跑和损坏或缺失附件 **MUST NOT** 被复核为成功。默认重试次数 **MUST** 为 0，首次报告和后续复核记录分别保留。

#### Scenario: 不完整执行无法通过复核
- **WHEN** 执行结果缺少声明的任一用例或附件，或存在跳过、flaky、失败
- **THEN** 执行器返回失败并记录具体原因，不覆盖原始结果
- **判据**:框架单测与合成浏览器回归分别验证这些失败输入和严格成功样本。

### Requirement: [FR-003] Cookie 认证上下文与安全清理

测试认证 **MUST** 使用当前 weiran4j Cookie/CSRF 契约和数字错误码，按角色、环境、地址及远端身份校验缓存；浏览器使用受保护的 storageState 复用 HttpOnly Cookie，写请求携带同一上下文的 CSRF 值。清理 **MUST** 验证 Cookie 与本地缓存移除、无凭据上下文重新鉴权失败，**MUST NOT** 声称普通登出吊销旧 JWT 或通过改密/递增 token_version 清理。

#### Scenario: 缓存主体和地址必须匹配
- **WHEN** 复用错误角色、错误地址、已失效或远端主体不一致的缓存
- **THEN** 认证上下文建立失败，业务测试不执行
- **判据**:session 单测和合成 HTTP 服务返回 401 或不同 user.id/username，fixture 拒绝复用。

#### Scenario: CSRF 与登出边界按实际契约验证
- **WHEN** 已登录上下文发起缺 CSRF 的写请求，随后正确携带 CSRF 登出并清除本地缓存
- **THEN** 缺 CSRF 的请求被 403/100103 拒绝；登出成功后该浏览器清 Cookie，无凭据访问返回 401/100101；结果不声称旧 JWT 被吊销
- **判据**:合成协议回归与真实会话流程分别核验响应和 storageState，清理失败保留私有恢复材料且运行失败。

### Requirement: [FR-004] 凭据与认证证据保护

凭据、Cookie、storageState 和恢复日志 **MUST** 只保存到被 Git 忽略且受权限保护的 tests/.local/，普通报告 **MUST NOT** 包含密码、Cookie、令牌或原始敏感输入调用日志。认证流程 **MUST** 禁用自动 trace、视频与截图，手工证据仅保存经过选择的状态字段和非敏感页面。

#### Scenario: 认证失败不泄漏材料
- **WHEN** 登录或认证缓存处理失败
- **THEN** 输出固定脱敏错误，普通运行产物不包含输入密码或 Cookie 值
- **判据**:使用合成的哨兵凭据触发输入、HTTP 和清理失败，扫描普通报告、控制台和附件无哨兵；私有缓存权限与忽略规则验证通过。

### Requirement: [FR-005] 系统流程的当前项目契约

系统测试 **MUST** 覆盖公开存活检查、匿名鉴权、登录入口、API Cookie 会话与浏览器会话，并为健康和匿名鉴权提供 Bruno 请求。健康结果 **MUST** 明确只代表存活，认证用例 **MUST** 核验当前主体与授权快照；缺真实服务、专用账号或必要前提时如实失败，不回退模拟成功。

#### Scenario: 基础流程按现有 HTTP 契约断言
- **WHEN** 在明确提供的本项目测试环境运行系统流程
- **THEN** 存活接口断言 HTTP 200/code 0/status UP，匿名访问断言 401/100101，登录入口经后台同源代理验证，认证流程核验本人资料及授权快照
- **判据**:系统步骤单测和 7 条流程的工具发现通过；真实执行报告逐项记录环境与结果，没有运行时明确标为未运行。

### Requirement: [FR-006] 离线校验与框架合成回归

测试工作流 **MUST** 提供不依赖账号或真实服务的声明、类型、用例发现、Bruno 语法和框架单测检查，以及独立的真实 Chromium + 合成服务回归。doctor 与执行器 **MUST NOT** 自动启停已有服务；文档 **MUST** 区分合成回归和真实业务通过，说明地址、凭据、清理及恢复方式。

#### Scenario: 无业务服务仍可检查框架
- **WHEN** 真实后端和后台未启动，执行 test:flows:check 及框架合成浏览器回归
- **THEN** 离线检查与合成服务独立运行；真实流程不会被这些结果标为成功
- **判据**:独立脚本退出码与产物证明合成服务启动/退出；doctor 探测不可达目标返回非 0，且没有启动业务服务。
