# sys_menu_structure_guard

## 0. 概要
菜单结构变更在多个实例之间的事务串行化边界。 system 内部表，无后台菜单。

## 1. 列表
无后台列表；只读排障从请求号、日志及数据库进入。

## 2. 字段与表单
id 固定为 1，主键；迁移初始化单行，不保存业务草稿。

## 3. 动作
新增、编辑/移动/改类型、删除用例事务的第一项数据库操作取得单行 SELECT FOR UPDATE；随后重新读取并校验层级，提交/回滚释放。独立语句超时 2 秒、菜单事务超时 3 秒，失败拒绝写入。

## 4. 用到的公共组件
领域端口及 Jdbc 实现由 system 自行装配；前端反馈与交互在 docs/page-states 演示。

## 5. 说明与建议
所有实例同步升级；维护窗口切换。仅通过授权用例维护，不依赖 Redis，也不承担 token_version 的令牌吊销职责。

## 6. 已知问题汇总
无新增待处理项；全局单行适用于后台低频管理写入，未进行大规模吞吐压测。
