## MODIFIED Requirements

### Requirement: [FR-006] 地区管理页面与导出

地区管理页面 **MUST** 提供地区筛选、树表格、展开折叠、增改删、启停和当前筛选结果 CSV 导出，并按权限显示操作；树表格 **MUST** 以 ID 为首列、同级 ID 倒序且保留至少一列弹性宽度。

页面 **MUST** 区分请求失败、成功无记录和成功无匹配结果；首次查询失败时持续显示错误与重试入口，后台刷新失败时保留已有数据并提示更新失败，重试沿用当前生效条件；筛选无匹配结果时提供清空条件入口。

新增或编辑弹窗 **MUST** 在实际修改后关闭前确认放弃，继续编辑保留输入，无修改或改回初值时直接关闭；保存中阻止关闭和重复提交，失败保留输入，成功正常关闭且不触发放弃确认。草稿 **MUST NOT** 写入持久存储或日志。

应用非空筛选条件后，页面 **MUST** 自动展开返回树中通往匹配节点的路径；用户随后仍可手动收起，同条件刷新 **MUST NOT** 强制恢复自动展开，清空全部条件后恢复默认折叠。

#### Scenario: 管理和导出地区
- **WHEN** 管理员使用地区页面筛选、维护或导出地区
- **THEN** 页面呈现树形结果及有权限的操作；导出包含筛选后的全部匹配记录，不受当前展开状态影响。
- **判据**: UI 树同级 ID 倒序且表格有弹性列；CSV 行数与同条件全量 API 结果一致。

#### Scenario: 地区查询失败与空结果恢复
- **WHEN** 地区查询首次失败、后台刷新失败，或成功但无匹配结果
- **THEN** 首次失败显示错误和重试，刷新失败保留旧数据并显示更新失败；无匹配时显示清空条件入口，且不会把错误表现成无记录。
- **判据**: 组件测试断言三种状态对应的内容、重试成功后的数据、清空条件后的请求。

#### Scenario: 地区表单关闭与保存保护
- **WHEN** 管理员关闭有修改的地区弹窗，或在保存期间尝试关闭及再次提交
- **THEN** 有修改时确认放弃且可继续编辑保留输入；无实际修改时直接关闭；保存期间禁止关闭与重复提交，失败保留输入，成功正常关闭。
- **判据**: 使用真实 Semi Form 的组件测试断言确认框、字段值、请求次数与弹窗生命周期。

#### Scenario: 筛选地区后显示命中路径
- **WHEN** 管理员应用非空地区筛选，返回结果包含匹配后代及必要祖先
- **THEN** 匹配后代无需再手动展开即可看到；手动收起后刷新同条件不重新展开；清空筛选恢复默认折叠。
- **判据**: 组件测试用省市县三级数据依次断言自动展开、手动收起、刷新保持和重置折叠。
