# E1 前端实现

## 完成的任务

- 1.1 列表持久错误、重试和成功空态。
- 1.2 两个新增/编辑弹窗实际修改确认及保存中保护。
- 1.3 地区筛选结果路径默认展开，手动折叠覆盖默认值，同条件刷新保持。
- 1.4 登记组件/hook 并同步用户与地区现状。
- 2.1 页面与真实 Semi Form 交互回归；2.2 门禁结果见最终 evidence 与 verify。

## 改了什么

- ListFeedback 在表格上方显示可重试的持续错误；ListEmptyState 只用于成功空结果，区分无记录与无匹配。
- useFormCloseGuard 在内存比较表单当前值与初值，忽略空字段注册差异；保存锁覆盖校验到请求完成，阻止重复提交与关闭。确认默认焦点为“继续编辑”。
- 地区展开采用 null 表示查询默认值、数组表示手动选择；无须使用数据更新 effect，因此同条件刷新不打断手动折叠。

## 为什么这么做

- 复用现有 Query 和 Semi UI，不新增依赖、不改请求接口。
- 不使用 touched 判定：编辑后恢复初值时应直接关闭。
- 不在每次 data 更新后自动展开：会覆盖手动折叠。
- 不持久化草稿：用户表单包含密码。

## 依赖的契约

沿用原用户分页、地区树与保存端点、数字 code=0、原权限控件；无后端契约变化。

- 原有 sys_task.md、部署文档与批处理兼容迁移完全保留，不属于本次改动。

## 埋的坑与验证发现

- Semi Table 的 empty=null 会回退为默认“暂无数据”；已改为显式的空 React 节点，并新增断言防止失败被显示为空数据。
- Semi Modal 取消事件有 100ms 防抖；回归用例分开验证不同关闭路径，避免把防抖误判为关闭保护失效。确认弹窗关闭动画在 jsdom 不可靠，确认本身使用 motion=false。
- 地区表单父级选项仍来自筛选树，是原有问题，本次不扩展处理，已登记 region.md#02。
