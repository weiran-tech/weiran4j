## 边界

### 要做

- 角色、菜单、字典、字典项四类编辑弹窗接入已有关闭与提交保护。
- 角色、菜单、字典主列表与字典项、登录日志和操作日志列表区分失败、缓存刷新失败及成功空结果，提供重试。
- 操作日志详情加载失败结束加载动画，显示错误与重试。
- 同步 docs 演示、必要回归测试及现状文档。

### 明确不做

- 不处理 P3 内置角色状态选项约束。
- 不扩展个人中心、系统配置、外部身份等其他表单的关闭保护。
- 不改后端接口、数据库、权限码、菜单、认证或全局重试策略。
- 不提交或推送工作区原有的任务文档、部署文档与批处理迁移改动。

### 本次不决定(留给后续 change)

- 全站表单离开路由或浏览器关闭时的草稿保护。

## 验收标准

- [ ] AC-1 四类弹窗无修改关闭不提示，有修改关闭须确认；继续编辑保留草稿，放弃才关闭。
- [ ] AC-2 四类弹窗校验及保存期间不重复提交、不响应关闭；失败后保留草稿并可重试，成功直接关闭。
- [ ] AC-3 六类列表（角色、菜单、字典、字典项、登录日志、操作日志）首次失败显示持续错误与重试，不显示成功空态；缓存刷新失败保留缓存且明确告知。
- [ ] AC-4 以上列表成功为空时显示准确空态；搜索列表提供清空筛选入口，保留既有分页和树展开行为。
- [ ] AC-5 操作日志详情首次失败不持续转圈，重试可恢复；缓存刷新失败保留详情并显示失败反馈。
- [ ] AC-6 docs 使用实际组件与本地数据覆盖新增交互，不请求真实业务服务；前端回归、docs 构建及仓库规定门禁通过。

## 关键取舍

| 取舍点 | 选择 | 放弃的方案 | 理由 |
|---|---|---|---|
| 实现方式 | 复用 useFormCloseGuard、ListFeedback 与既有查询状态 | 新建表单框架或全局自动重试 | 已有模式成熟，增量修改可独立验证 |
| 状态保存 | 内存保留草稿与查询缓存 | 写入本地存储 | 避免敏感编辑内容持久化 |
