## MODIFIED Requirements

### Requirement: [FR-014] 用户列表查询反馈与恢复

用户、角色、菜单、字典及字典项、登录日志和操作日志管理页面 **MUST** 区分请求失败、成功无记录和成功无匹配结果；查询失败时持续显示错误与重试入口，后台刷新失败时保留已有数据并明确告知更新失败。重试 **MUST** 沿用当前已生效筛选和分页，成功后清除错误反馈；无匹配结果 **MUST** 提供清空条件入口。

#### Scenario: 首次查询失败后重试成功
- **WHEN** 用户列表首次查询失败，用户随后点击重试且请求成功
- **THEN** 失败阶段显示持久错误提示而非无记录提示，重试后显示返回数据且错误消失。
- **判据**: 组件测试模拟先失败后成功，断言错误提示、重试请求参数、数据行和错误提示移除。

#### Scenario: 后台刷新失败保留已有数据
- **WHEN** 已展示用户数据后，同一查询刷新失败
- **THEN** 页面仍显示已有数据，并显示更新失败与重试入口。
- **判据**: 组件测试断言刷新失败后旧用户行仍存在，并可点击重试。

#### Scenario: 空结果与查询条件对应
- **WHEN** 用户列表成功返回空列表
- **THEN** 无条件查询显示无记录；有条件查询显示无匹配结果，清空条件后回到未筛选第一页。
- **判据**: 组件测试分别断言两种空态文案，并验证清空条件的请求参数。

#### Scenario: 后台列表采用一致查询反馈
- **WHEN** 角色、菜单、字典主列表、字典项、登录日志或操作日志首次失败或缓存刷新失败
- **THEN** 各查询持续显示对应错误并可原地重试，保留既有数据、筛选、分页和菜单树展开状态；成功为空才显示空态，有筛选时可清空条件回第一页。
- **判据**: 参数化组件测试覆盖六类列表的首次失败、恢复与缓存刷新失败，并检查空态不误报。

#### Scenario: 字典主从查询分别恢复
- **WHEN** 字典主列表或当前字典项查询失败
- **THEN** 对应区域提供重试；主列表首次失败不显示请选择字典，已有选中字典与字典项不因刷新失败被清除。
- **判据**: 组件测试分别注入左右查询失败并断言提示、重试请求及已选项保持。

### Requirement: [FR-015] 用户编辑弹窗输入保护

用户、角色、菜单、字典和字典项新增和编辑弹窗 **MUST** 在内容相较初值实际改变时，关闭前要求确认放弃；继续编辑 **MUST** 保留输入，无改动或恢复初值时 **MUST** 直接关闭。校验与保存请求进行中 **MUST** 阻止关闭和重复提交，失败保留输入，成功正常关闭且不触发放弃确认。保护过程 **MUST NOT** 持久化或记录表单草稿。

#### Scenario: 有改动时继续编辑或放弃
- **WHEN** 用户修改字段后点击取消、关闭按钮或按 Esc
- **THEN** 弹出放弃修改确认；选择继续编辑保留字段，确认放弃才关闭原表单。
- **判据**: 组件测试断言关闭确认出现、继续编辑后输入保留、确认放弃后弹窗移除。

#### Scenario: 无实际改动时直接关闭
- **WHEN** 用户未编辑，或把字段恢复到初值后关闭弹窗
- **THEN** 弹窗直接关闭且不显示放弃确认。
- **判据**: 组件测试覆盖未改动和改回初值两种路径。

#### Scenario: 保存期间和保存结果保护
- **WHEN** 用户发起有效保存并尝试再次保存或关闭，随后请求失败或成功
- **THEN** 等待期间维持弹窗且只发出一次保存；失败保留输入，成功关闭且无放弃确认。
- **判据**: 组件测试用可控异步请求断言请求次数、等待中的弹窗和完成后的状态。

#### Scenario: 后台编辑弹窗保护一致
- **WHEN** 管理员使用角色、菜单、字典或字典项编辑弹窗
- **THEN** 无改动关闭、变更确认、继续编辑、保存期互斥、失败保留草稿及成功关闭均遵循相同保护规则。
- **判据**: 四类实际弹窗组件回归覆盖取消、关闭、Esc、失败和成功，且延迟校验或保存阶段只发起一次写请求。

### Requirement: [FR-018] 页面状态文档演示

页面示例与组件演示 **MUST** 统一位于 docs 文档站并随实际交互更新；权限分配、设置读取、权限同步、编辑保护、列表查询和操作日志详情恢复 **MUST** 提供可交互的加载、失败、重试、禁用与更新后状态演示。演示 **MUST** 使用本地示例数据并复用实际状态呈现组件或共用判定逻辑，不依赖登录、真实业务数据或生产接口。

#### Scenario: 文档站切换并恢复页面状态
- **WHEN** 读者进入页面状态演示并选择权限分配、安全设置、上传设置或权限同步场景
- **THEN** 可操作相应状态，观察失败时保存不可用、重试恢复数据、权限更新后菜单与按钮变化。
- **判据**:浏览器验证各演示场景可切换与操作，模拟失败不产生业务接口请求；文档站构建成功，AGENTS.md 包含统一归属说明。

#### Scenario: 编辑与查询恢复演示
- **WHEN** 读者进入编辑保护、列表查询或日志详情场景
- **THEN** 可以操作正常、加载、空数据、首次失败、缓存刷新失败、重试和保存保护状态；演示使用实际公共组件与本地数据。
- **判据**: 浏览器验证场景切换与恢复，确认无业务服务请求，文档站构建成功。

## ADDED Requirements

### Requirement: [FR-020] 操作日志详情读取恢复

操作日志详情 **MUST** 区分读取中、读取失败和成功数据；首次失败后结束加载动画，显示持续失败说明与就地重试入口。已有详情刷新失败时 **MUST** 保留可读缓存并提示更新失败；重试 **MUST** 沿用当前日志 ID，成功后移除错误提示。

#### Scenario: 详情首次失败后重试恢复
- **WHEN** 用户打开操作日志详情，首次读取失败并点击重试
- **THEN** 失败阶段显示错误而非持续加载；重试成功后显示当前日志详情。
- **判据**: 组件测试断言失败时无加载状态、存在错误与重试，重试沿用 ID 并恢复真实数据。

#### Scenario: 详情缓存刷新失败
- **WHEN** 已有日志详情的查询刷新失败
- **THEN** 详情保留，显示更新失败和重试；成功后清除错误，保持查看当前日志。
- **判据**: 测试预置缓存后触发失败，断言详情字段仍在且重试更新后错误消失。
