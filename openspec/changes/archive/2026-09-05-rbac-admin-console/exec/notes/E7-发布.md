# E7: 发布验证

## 完成的 tasks.md 条目

- 7.1、7.2

## 改了什么

无代码改动，纯验证性单元。

## 为什么这么做

- `./gradlew check` 是仓库全量质量门禁（编译 + 测试 + Checkstyle + SpotBugs + Forbidden APIs + Error Prone/NullAway + 覆盖率），跑一次确认整个 change 的所有改动组合起来仍然全绿，而不是只看各单元各自的编译结果。
- `vite build` 验证前端生产构建产物能正常生成，不只是开发模式/测试模式能跑。

## 依赖的契约

无新增契约依赖，验证的是 E1-E6 全部代码组合后的构建结果。

## 越界申报

无。

## 埋的坑 / 遗留

- [ ] `exec/permission-seed.sql` 仍需人工在目标环境执行（本地无可连接的真实数据库），发布流程里这是一个人工步骤，未自动化。
