## 改了什么

- MediaObjectNames 新增显式 folder 生成入口与 OSS 专用校验入口；原入口及本地校验仍固定 media。
- OssFileStorage 的代传和授权读取同一配置，inspect/delete 识别安全历史单级根目录。

## 为什么这么做

- 删除只认当前配置会使历史目录失效，因此允许安全文件夹加规范用户对象结构，并继续由已登记资源及引用保护控制删除。
- 未将可配置目录应用到本地或批处理路径，避免范围扩大。

## 依赖的契约

- exec/plan.md §4 folder 格式与默认值，原票据签名/用户/前缀/时效保持不变。
