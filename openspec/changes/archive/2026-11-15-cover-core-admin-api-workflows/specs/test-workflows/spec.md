## ADDED Requirements

### Requirement: [FR-007] 核心业务 API 工作流覆盖

API 工作流 **MUST** 覆盖核心后台读取、用户/角色/菜单/字典/配置生命周期、受限账号权限变化和地区只读查询。断言 **MUST** 同时核验 HTTP 状态、数字 code、业务返回形状和状态变化，合法空结果不得当失败；读取结果和恢复证据不得包含真实用户、配置或审计明文。

#### Scenario: 核心接口返回契约可验证
- **WHEN** 使用专用测试身份运行核心读取及地区读取流程
- **THEN** 分页校验 list/total/page/pageSize，菜单和地区按实际数组/树契约核验；匿名调用受保护接口为 401/100101
- **判据**:发现 8 条新增流程；注入字符串 code、缺失 total、错误树结构的离线响应时失败，合法空数组通过；合成装配与真实报告分别标明环境。

#### Scenario: 生命周期与业务约束可重复验证
- **WHEN** 在显式允许写入的测试环境运行资源生命周期
- **THEN** 创建、读取、修改、删除均观察到状态结果；重复键、陈旧版本、菜单成环/非叶删除、字典启用项与配置公开边界按现有业务契约检查
- **判据**:每类流程具有 before/after/cleanup 证据，错误响应或修改未生效令流程失败；删除后读取或精确查询证明本次资源已不存在。

### Requirement: [FR-008] 测试业务数据所有权与恢复

业务写入测试 **MUST** 在首次登录或写入前确认显式 ALLOW_WRITE=true，且仅修改本次唯一标记创建的普通资源。测试 **MUST** 在写前私有登记创建意图，按依赖逆序清理并验证结果；中断、响应不确定或清理失败时保留恢复清单，执行失败。恢复 **MUST** 精确校验环境、资源类型、身份与父级，禁止按通用前缀批删、重发不确定创建或修改既有数据。

#### Scenario: 未授权写入和错误所有权被拒绝
- **WHEN** 未开启写入或恢复材料指向其他环境、既有资源、错误父级或损坏数据
- **THEN** 测试在业务写入前失败，不修改目标资源，也不删除恢复材料
- **判据**:请求记录中无相应写调用；凭据缺失、开关为 false、地址篡改、身份不符和路径链接越界负例均返回失败。

#### Scenario: 不确定创建和失败清理能够恢复
- **WHEN** 创建响应丢失、用例断言失败或删除连接失败
- **THEN** 使用事先登记的精确唯一标识定位本次资源；清理不可确认时失败并保留私有记录，后续恢复只清理经核验的记录
- **判据**:合成服务在写后断连接、删除失败及重复恢复场景中验证不重复创建、不误删、材料为 0600；恢复后精确查询无剩余资源。

### Requirement: [FR-009] 受限账号权限生命周期验证

权限工作流 **MUST** 使用测试创建的普通用户与角色，引用已有权限定义，验证同一 Cookie 会话的授权、越权拒绝与撤权后校准。测试 **MUST NOT** 修改操作者、已有账号或内置角色；被测主体与操作主体的 Cookie/CSRF 必须隔离，权限不足不得与匿名或 CSRF 错误混淆。

#### Scenario: 同一主体撤权后访问被拒绝
- **WHEN** 临时用户获授一个既有读取权限并登录，管理员随后只撤回其临时角色的授权
- **THEN** 允许请求为 code 0，未授予及撤回后的对应受保护请求为 403/100102；授权快照身份一致且修订发生变化
- **判据**:成功、错误 HTTP/业务码、两个主体串用 Cookie、撤权后仍成功的响应均由真实步骤断言；最终用户先删除、角色后删除，既有角色授权不变。
