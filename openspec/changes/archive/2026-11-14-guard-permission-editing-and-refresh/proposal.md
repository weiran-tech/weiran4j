# Proposal

## Why

- 角色详情失败被解释为空权限且仍可保存，可能造成非用户意愿的权限清空。
- 安全/上传设置首次读取失败后无限显示加载；角色变更后当前界面使用旧权限。
- 用户要求相关页面状态同步到 docs 做演示，所有页面示例与组件演示的归属在 AGENTS.md 明确。
- 需求来源：interview.md；现状与复用点见 explore.md。

## What Changes

- 权限分配只有必要数据可靠可用时允许编辑和保存，失败提供重试。
- 安全/上传设置提供可恢复的错误态，保留草稿并保护保存前置条件。
- 角色写入成功后同步刷新本会话资料与菜单，保留既有资源失效行为。
- docs 增加本地可交互状态演示，复用实际页面无请求的状态视图或共用判定逻辑；AGENTS.md 演示归属规则已更新。

## Scope

### In Scope

- RoleMenuSheet、SecuritySettingsPage、UploadSettingsPage、roles Query hooks 及相应回归。
- docs 状态演示页、现有 Vue/React 桥接接入、导航入口与必要组件登记；AGENTS.md 规则和模块现状。

### Out of Scope

- 不修改后端接口、鉴权规则、权限码、菜单、数据库和依赖。
- 不修上传设置多项保存的原子性问题，不改地区父级选项和窄屏查询。
- 不引入跨标签页或跨账号的权限实时推送，不扩展用户/菜单等其他资源的写入流程。
- 不自动提交、推送、归档或发布；不改原有三处无关工作区内容。

## Dependencies

- 复用现有 Semi UI、TanStack Query、Permission、ListFeedback 与文档演示桥接；不安装新依赖。
- 后端、数据库、部署配置均无变化；docs 使用本地数据，导入实际的无请求视图，必要时增加前端源码路径解析。
- 测试沿用已有渲染和接口模拟工具；docs 构建和浏览器状态演示另做验证。

## Risks

| 风险 | 触发场景 | 应对 |
|---|---|---|
| 空列表与失败混淆 | 两个查询部分失败 | 按查询成功和刷新状态保护，保留合法空权限操作 |
| 当前权限减少 | 修改本人所属角色 | 当前界面按新接口结果呈现，路由兜底沿用现状 |
| 演示漂移 | 文档复制业务条件 | 共用实际状态视图和判定，使用虚构数据 |
