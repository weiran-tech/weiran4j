## 边界

### 要做

- 角色权限分配：菜单树和角色详情读取失败时禁止保存及修改选项，提供错误与重试。
- 安全设置、上传设置：区分加载与失败，针对必要查询提供重试；依赖数据失败时禁止保存。
- 角色新增/编辑、删除、分配菜单成功后，使当前用户资料与菜单查询失效并刷新，现有角色资源失效逻辑保留。
- 故障恢复与界面权限同步回归测试，更新 sys_role.md#01/#06 与 sys_config.md#06。
- docs 提供权限分配、安全设置、上传设置与权限同步的可交互状态演示，复用实际交互逻辑，使用本地示例数据。

### 明确不做

- 不修改后端接口、鉴权规则、权限码、菜单、数据库和依赖。
- 不修上传设置多项保存的原子性问题，不改地区父级选项和窄屏查询。
- 不引入跨标签页或跨账号的权限实时推送，不扩展用户/菜单等其他资源的写入流程。
- 不自动提交、推送、归档或发布；不改原有三处无关工作区内容。

### 本次不决定(留给后续 change)

- 其他页面接入错误恢复和未保存保护的顺序。

## 验收标准

- [x] AC-1 菜单树或角色详情首次读取失败时，显示错误及重试，保存禁用，不能提交默认空 menuIds；任一依赖失败均受保护。
- [x] AC-2 重试成功后恢复已有勾选，用户可正常编辑和保存；两份数据均成功且真实为空时仍允许明确清空，不误把空数据等同失败。
- [x] AC-3 安全设置首次失败不再显示无限加载；重试成功呈现真实设置。后台刷新失败时保留可读数据、显示错误并禁止依赖旧数据保存。
- [x] AC-4 上传设置的上传规则查询与配置列表查询分别失败时均可重试，必要数据未恢复前禁止保存；重试保留已输入草稿。
- [x] AC-5 角色创建/编辑、删除和分配菜单成功后，当前会话资料与菜单查询重新读取，Permission 按钮和导航采用新权限；写入失败不刷新身份缓存。
- [x] AC-6 回归测试、构建、lint 和 OpenSpec 校验有真实结果；本轮不涉及的原有改动保留。
- [x] AC-7 docs 可切换并演示加载、失败、重试恢复、保存禁用及权限更新结果；不依赖登录或真实业务接口；文档站构建通过，AGENTS.md 已明确所有页面示例与组件演示归属 docs。

## 关键取舍

| 取舍点 | 选择 | 放弃的方案 | 理由 |
|---|---|---|---|
| 权限保存前置 | 两个查询成功且没有失败/刷新中状态才允许编辑和保存 | 失败时把默认空数组当合法初始值 | 避免非用户意愿的清空 |
| 身份同步 | 本会话角色写入成功后主动失效资料和菜单 | 每隔数秒轮询全部身份数据 | 不引入常驻请求与新协议 |
| 设置重试 | 保留本地草稿，恢复必要查询 | 整页强制刷新 | 防止丢失已填写设置 |
