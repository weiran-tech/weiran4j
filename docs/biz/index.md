# 业务定义

业务对象、角色、规则、状态、场景和验收定义按业务域组织在 `docs/biz/<业务域>/`。以 weiran4j 当前实现为准，扩展业务明确标注归属；不把其他项目的业务能力纳入本仓基线。

## 业务域

| 业务域 | 定义范围 | 归属 |
| --- | --- | --- |
| [身份与权限](identity-access/index.md) | 用户、角色、菜单、授权、会话及允许/拒绝场景 | system 基座 |
| [基础配置](configuration/index.md) | 字典、配置分组、公开配置边界 | system 基座 |
| [行政区划](region/index.md) | 地区树、查询与详情边界 | 本仓行政区划扩展 |

本次从 `tests/docs/coverage.md`、流程说明和项目契约整理现有验收视角，日期为 2026-11-19。没有重新执行真实业务；已编写、合成通过、真实未运行等状态保持原样。完整规则以项目规格、代码和 OpenAPI 为准。

## 编写规则

每个业务域说明对象、角色和操作、已确认规则、可观察场景、数据前提、清理约束、流程映射、未覆盖项及来源。较大业务可继续拆分 roles.md、rules.md、scenarios.md 等主题。

业务状态使用领域状态；测试的未执行、阻塞、合成通过和真实结果分别记录。未知规则明确待确认，不因已有用例名称就推断产品能力已经实现。

业务定义归本目录，测试组织、运行、留证和恢复规则见 [测试框架基线](../testing/index.md)。具体接口字段以 OpenAPI 为准；端口、账号注入和执行入口见 [项目测试工作流](../testing.md)。真实数据、凭据和运行附件不进入本目录。
