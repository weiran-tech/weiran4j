# 基础配置

适用范围：本仓 weiran4j。来源：项目 `tests/docs/coverage.md`、`writing-flows.md`。当前字典与配置生命周期已编写，离线和合成结果不能代替真实业务验收。

## 业务对象

字典包含分组与字典项，提供排序、启用过滤及关联行为。系统配置包含分组和配置项；后台管理与公开读取使用不同边界。维护操作要求相应权限，公开读取不得泄露后台配置。

## 场景与判据

| 对象 | 已有验收场景 | 可观察判据 |
| --- | --- | --- |
| 字典及项 | 创建、读取、修改、删除 | 回读状态与操作一致，不只检查请求成功 |
| 字典项顺序及启用 | 排序与启用过滤 | 查询结果符合既有项目契约 |
| 字典删除 | 关联项级联行为 | 父级与相关子项的查询结果确认删除效果 |
| 配置分组及项 | 创建、读取、修改、删除 | 状态变化、关联关系和本次数据清理可确认 |
| 非空配置分组 | 删除保护 | 被项目既有业务约束拒绝 |
| 公开配置 | 白名单边界 | 只返回允许公开的字段；不能虚构自定义公开开关 |

业务码、字段、排序和级联细节以项目实现为准，不推断其他项目采用相同模型。

## 数据与映射

使用本次唯一标记创建的普通分组和项，按依赖逆序清理；不能修改现有配置以制造成功前提。清理失败留下私有清单并使流程失败。

流程：`system/dict-lifecycle`、`system/config-lifecycle`；相关读取由 `system/core-read` 覆盖。来源说明记录真实业务尚未运行；没有对应真实报告时不得写为当前环境已通过。
