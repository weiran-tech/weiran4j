# 测试框架基线

以 weiran4j 当前 `tests/` 实现为基线，维护可供下游采用的目录、命令、流程、证据和恢复约定。采用方须单独验证项目协议与业务适配，不因复制文档就视为完成接入。

本目录定义测试如何组织和执行；业务对象、角色、规则、场景及验收定义按业务域放在 [业务定义](../biz/index.md)。当前环境与命令快速入口见 [项目测试工作流](../testing.md)。

## 阅读入口

| 需要做什么 | 文档 |
| --- | --- |
| 了解目录、声明、标签与适配边界 | [工作区与声明](structure.md) |
| 浏览、检查、执行流程和配置 Turbo | [运行与检查](running.md) |
| 新增流程、共享步骤或 Bruno 请求 | [编写流程](writing-flows.md) |
| 查看批次、复核结果和保护敏感材料 | [证据与报告](evidence.md) |
| 隔离数据、清理会话与恢复资源 | [资源与恢复](resources.md) |
| 区分覆盖、阻塞和验证层次 | [覆盖与验收口径](coverage.md) |

## 内容归属

| 内容 | 维护位置 |
| --- | --- |
| 公共框架目录、命令、声明、标签、证据和恢复原则 | `docs/testing/` |
| 业务对象、角色、规则、场景与验收定义 | `docs/biz/<业务域>/` |
| 当前环境、认证契约、资源支持范围和快速操作 | [项目测试工作流](../testing.md)及项目契约 |
| 流程实现、注册表、共享步骤索引 | `tests/` |
| 执行结果、当前阻塞与历史验证入口 | `tests/docs/coverage.md` 及项目验证记录 |
| 凭据、会话和恢复材料 | 被忽略的 `tests/.local/` |
| 批次、原生报告与附件 | 被忽略的 `tests/.artifacts/` |

同名业务和框架在下游可以存在协议适配，不能以基线覆盖本地契约。HTTP 路径和字段以 OpenAPI 为准，不在文档重复维护完整 API 清单。

## 来源与维护

整理日期：2026-11-19。公共内容提炼自本仓 `tests/docs/running.md`、`writing-flows.md`、`coverage.md` 及 `tests/framework/README.md`，并按已确认的统一目录、Turbo/Node 编排、默认全量和资源恢复机制整理。

后续公共约定在本目录维护，业务定义在 docs/biz 按域维护；tests/docs 保留执行相关补充、项目适配和验证记录入口。修改实现时核对两侧口径。历史证据、业务阻塞和执行事实不因文档整理改写。
