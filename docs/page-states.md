# 页面状态演示

这些交互示例使用本地虚构数据，无需登录。读取保护与错误反馈复用后台实际使用的 `queriesReady`、`QueryReadiness`，权限按钮复用 `Permission`；切换状态不会请求业务接口。

- **编辑冲突**：修改昵称并模拟其他人保存，观察版本冲突保留输入；确认重载或模拟重载失败，恢复后再保存，切换编辑权限检查禁用状态。
- **认证限流**：模拟额度耗尽、提交中与手动恢复；限流不清会话，不自动重发，可切换本地密码能力。
- **编辑保护**：实际关闭保护配合 Semi Form；修改后尝试取消、关闭或 Esc，选择继续编辑或放弃，模拟保存失败及延迟完成。
- **列表反馈**：切换六类列表示例，查看加载、成功空结果、首次失败与缓存刷新失败；重试及清空筛选恢复。
- **日志详情**：复用实际 `OperationLogDetails`，首次失败结束加载并提供重试，缓存刷新失败保留字段。
- **权限分配**：分别让菜单树和角色详情失败；未恢复前不能勾选或保存。成功的空权限仍可以明确保存。
- **安全设置**：首次失败提供重试，缓存刷新失败保留可读设置并禁止保存。
- **上传设置**：上传规则与配置列表分别恢复；输入草稿在失败、重试后保留。
- **异常恢复**：模拟页面渲染、首次模块加载与持续失败，使用实际恢复组件重试、返回首页；导航外壳保留。
- **窄屏搜索**：快捷和高级输入共用草稿；缩小窗口后通过高级筛选按昵称查询、移除条件或重置。
- **权限同步**：可切换角色或菜单变更来源；模拟角色写入成功后重取当前资料及菜单，观察操作按钮与导航更新；失败保留原权限。

页面示例与组件演示统一放在 docs；新增交互时同步演示的相关状态。公共组件见[组件总览](./components/)。上传配置逐项保存的原子性不在本次演示范围。
