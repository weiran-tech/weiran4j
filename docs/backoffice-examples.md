# 后台页面示例

七类后台页面已拆为独立文档页面，无需登录或启动后端，可通过左侧分组菜单直接访问。

- [列表与筛选](/backoffice-examples/list)：使用本地字典与数据，支持搜索、筛选、列设置和状态切换。
- [导航列表](/backoffice-examples/navigation)：使用真实导航列表组件展示分组搜索、选择与空结果。
- [字段与标签](/backoffice-examples/fields)：使用本地字典演示选项、状态标签与图标选择。
- [权限与入口](/backoffice-examples/access)：切换模拟操作权限，检查按钮展示及无权限提示。
- [配置表单](/backoffice-examples/config)：复用实际动态表单，演示全部字段、上传组合、特殊校验、只读与保存或上传失败重试；保存仅影响当前页面，上传使用临时 URL。
- [自增序号](/backoffice-examples/sequence)：本地模拟按标识独立递增、非法标识与分配失败；真实并发和事务语义由后端测试覆盖。
- [批处理任务](/backoffice-examples/batch)：复用实际工作台，通过本地数据源模拟上传、预检、决策、入库、总结、取消与失败重试，不解析文件或写入业务数据。

更多交互状态见[页面状态演示](/page-states)，维护方式见[演示开发约定](/examples/)。真实文件解析、并发、唯一性和事务语义继续由后端测试覆盖。
