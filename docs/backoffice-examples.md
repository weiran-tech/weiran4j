# 后台页面示例

这些页面已从业务后台拆出，无需登录或启动后端。选择下方页面即可操作：列表、导航、字段与标签、权限展示、配置表单、自增序号和批处理工作台。

<ClientOnly><BackofficeDemo /></ClientOnly>

列表使用本地字典与数据，支持筛选、列设置和状态切换；权限入口使用模拟权限。配置表单复用实际动态字段与校验，保存只影响当前页面，刷新后重置；只读、保存失败和上传失败可单独切换，失败后保留输入并可重试。文件仅生成浏览器临时 URL，不进入资源库。

自增序号只模拟按标识递增，不代表真实数据库分配。批处理复用实际工作台，选择对应扩展名文件后点击“上传并开始处理”，再用“推进模拟阶段”查看各阶段；可模拟读取、上传和部分失败，支持取消。示例不解析文件，也不写入业务数据。真实唯一性、并发、文件解析和事务语义由后端集成测试覆盖。

更多加载、空数据、失败恢复、权限变化和关闭保护场景见[页面状态演示](/page-states)。源码与新增方式见[演示开发约定](/examples/)。
