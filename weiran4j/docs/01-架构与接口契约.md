# weiran4j 架构与接口契约（v2 重写）

> 本文是 2026-09-26 重写的**唯一契约来源**。前后端都按本文实现；实现与本文不符时，先改本文再改代码。
>
> 重写的三条前提（D-008）：
> 1. **不再兼容 PHP weiran-v1**：不读写 `pam_*` 表，不保留历史密码算法，不保留 `/api/v1` 前缀。
> 2. **去掉 wuli3 底座**：直接基于 Spring Boot 3.5 + MyBatis-Plus + Flyway，clone 即可构建。
> 3. **能力对标 mono4ts 的「标准后台底座」**：登录/JWT、用户、角色、菜单（动态路由 + 按钮权限）、部门、
>    字典、系统配置、登录日志、操作日志；前端 Semi Design 后台布局。

## 2. Gradle 模块

```
weiran4j/
├── build-logic/                 # 约定插件（质量门禁唯一来源）
├── weiran-dependencies/         # BOM：import spring-boot-dependencies + mybatis-plus-bom，钉 jjwt/springdoc/testcontainers 版本
├── weiran-common/               # 纯 Java：ErrorCode / BizException / CommonErrors / PageQuery / PageResult / ApiResponse
├── weiran-framework/            # Spring 基础设施（替代 wuli3）：统一响应、全局异常、认证拦截、权限注解、操作日志切面、MyBatis-Plus 配置
├── weiran-system/               # 身份与权限（DDD 五层）：auth / user / role / menu / department / login-log
│   └── weiran-system-{api,domain,application,infrastructure,adapter}
├── weiran-platform/             # 平台能力（DDD 五层）：dict / config / operation-log
│   └── weiran-platform-{api,domain,application,infrastructure,adapter}
└── weiran-app/                  # 启动模块：只聚合依赖 + application.yml + 集成测试
```

依赖方向：`adapter → application → domain`，`infrastructure → domain`，`application → api`。
`weiran-framework` 可被 adapter / infrastructure / application 依赖；**domain 与 api 只能依赖 weiran-common**。

各层职责：

| 层 | 放什么 | 禁止 |
| --- | --- | --- |
| api | 对外 DTO（record）、应用服务接口、命令对象 | Spring、MyBatis |
| domain | 聚合/实体/值对象、领域规则、仓储端口（接口） | 任何框架 |
| application | 实现 api 的服务接口，编排用例，`@Transactional` 边界 | `*DO`、Mapper |
| infrastructure | `*DO`、Mapper、仓储实现、JWT、BCrypt、Flyway 脚本 | Controller |
| adapter | `@RestController`、请求 DTO 与校验、`@RequiresPermission`、`@OperationLog` | 直接调 Mapper |

每个模块用 `@AutoConfiguration` + `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`
自我登记；Mapper 用 `@MapperScan` 写在该模块 infrastructure 的自动配置里。`weiran-app` 不写 `@ComponentScan`。

## 3. weiran-framework 提供的扩展点

| 类型 | 名称 | 说明 |
| --- | --- | --- |
| 注解 | `@PublicApi` | 标在 Controller 类或方法上：无需登录 |
| 注解 | `@RequiresPermission(value = {"system:user:list"}, logical = ANY)` | 需要任一权限码；超管角色 `super_admin` 直接放行 |
| 注解 | `@OperationLog(module = "用户管理", description = "新增用户")` | 切面记录操作日志（请求体脱敏 `password` 等字段、截断 4096） |
| SPI | `TokenAuthenticator` | `Optional<LoginUser> authenticate(String bearerToken)`；由 system 模块实现 |
| SPI | `OperationLogRecorder` | `void record(OperationLogEvent event)`；由 platform 模块实现（异步落库，失败只记日志不影响业务） |
| SPI | `AuditorProvider` | 给 MyBatis-Plus 自动填充 `created_by/updated_by`；默认从 `CurrentUser` 取 |
| 工具 | `CurrentUser` | `static Optional<LoginUser> get()` / `LoginUser require()`（未登录抛 401） |
| 记录 | `LoginUser(long id, String username, String nickname, Set<String> roles, Set<String> permissions)` | `isSuperAdmin()` = roles 含 `super_admin` |

认证流程：`AuthInterceptor`（HandlerInterceptor，只拦 `/api/**`）→ 读 `Authorization: Bearer <token>` →
`TokenAuthenticator` → 放入 `CurrentUser`（ThreadLocal，`afterCompletion` 清理）→ 没有 `@PublicApi` 且未登录返回 401 →
检查 `@RequiresPermission`，不满足返回 403。拦截器里抛 `BizException`，由全局异常处理器统一输出。

令牌吊销：用户表 `token_version` 列。JWT 里带 `ver` claim；改密码 / 禁用 / 管理员重置密码时 `token_version + 1`，
旧令牌立即失效。`TokenAuthenticator` 每次请求查库（用户 + 角色 + 权限码），结果可短缓存（Caffeine 30s）但改权限后需失效。

## 4. HTTP 约定

- 前缀统一 `/api`；JSON 字段 camelCase；时间格式 `yyyy-MM-dd HH:mm:ss`（`Asia/Shanghai`）；ID 为数字（bigint 自增）。
- 统一响应（HTTP 状态码与 `code` 一致或为 200）：

```jsonc
{ "code": 0, "message": "ok", "data": { ... } }          // 成功，code 恒为数字 0
{ "code": 40100, "message": "登录已失效，请重新登录", "data": null }  // 失败
```

- 错误码：五位数字，前三位 = HTTP 状态码。通用码在 `CommonErrors`：

| code | HTTP | 含义 |
| --- | --- | --- |
| 40000 | 400 | 参数校验失败（message 形如 `username: 不能为空`） |
| 40100 | 401 | 未登录 / 令牌无效 / 已失效 |
| 40101 | 401 | 用户名或密码错误 |
| 40300 | 403 | 无权限 |
| 40301 | 403 | 账号已禁用 |
| 40400 | 404 | 资源不存在 |
| 40900 | 409 | 唯一键冲突（如用户名、角色编码、字典编码已存在） |
| 40901 | 409 | 业务状态冲突（如删除有子节点的部门/菜单、删除内置数据） |
| 50000 | 500 | 服务器内部错误（message 不暴露堆栈） |

- 分页：请求参数 `page`（从 1 开始，默认 1）、`pageSize`（默认 20，最大 200）；响应 `data` = `{ list, total, page, pageSize }`。
- 状态字段统一字符串枚举：`status: "enabled" | "disabled"`。
- 库中 tinyint 标志位（`visible`、`keepAlive`、`isExternal`、`isBuiltin`、`success`）在 JSON 中一律为 **boolean**。
- `PUT /api/roles/{id}/menus` 的 `menuIds` 可包含 directory 类型节点（前端勾选子节点会连带勾选祖先）。

## 5. 数据库（MySQL 8，Flyway）

脚本放在各模块 infrastructure 的 `src/main/resources/db/migration/<module>/`，文件名
`V<yyyyMMddHHmm>__<module>_<desc>.sql`（版本号全局唯一，按时间排序）。`spring.flyway.locations=classpath:db/migration`（递归子目录）。
所有表 `utf8mb4` / `InnoDB`；通用列：`id bigint auto_increment`、`created_at datetime not null default current_timestamp`、
`updated_at datetime not null default current_timestamp on update current_timestamp`、`created_by bigint null`、`updated_by bigint null`。
**不建外键约束**（应用层保证），关联列建索引。

## 6. 接口清单

标注：🔓 = `@PublicApi`；🔑 = 仅需登录；其余为所需权限码。写操作均带 `@OperationLog`。

### 6.1 认证 `/api/auth`（system）

| 方法 | 路径 | 权限 | 请求 | 响应 data |
| --- | --- | --- | --- | --- |
| POST | /login | 🔓 | `{username, password}` | `{accessToken, tokenType:"Bearer", expiresIn(秒)}` |
| POST | /logout | 🔑 | — | null（写登出日志） |
| GET | /me | 🔑 | — | `CurrentUserView{id, username, nickname, email, phone, avatar, gender, departmentId, departmentName, roles:string[], permissions:string[]}`；超管 permissions 返回 `["*"]` |
| GET | /menus | 🔑 | — | 当前用户可见菜单树 `MenuNode[]`（仅 directory/menu，status=enabled；超管=全部；visible=false 的也返回，前端据此只注册路由不显示） |
| PUT | /profile | 🔑 | `{nickname, email?, phone?, avatar?, gender?}` | null |
| PUT | /password | 🔑 | `{oldPassword, newPassword}`（新密码 8–64 位，含字母与数字） | null；成功后 token_version+1，前端需重新登录 |

登录规则：用户名不存在与密码错误**同一个错误码 40101**（防枚举）；禁用账号 40301；成功/失败都写 `sys_login_log`；
成功后更新 last_login_at/ip。JWT：HS256，claims `sub`=userId、`username`、`ver`，有效期默认 12h，密钥 ≥ 32 字节，缺失则启动失败。

`MenuNode = {id, parentId, title, type, path, component, icon, permission, sort, visible, keepAlive, isExternal, status, children: MenuNode[]}`

### 6.2 用户 `/api/users`

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | / | system:user:list | 分页；查询 `keyword`(用户名/昵称/手机)、`status`、`departmentId`(含子部门) → `UserView[]` |
| GET | /{id} | system:user:list | `UserView` |
| POST | / | system:user:create | `{username, nickname, password, email?, phone?, gender?, departmentId?, status?, roleIds: number[]}` → `{id}` |
| PUT | /{id} | system:user:update | 同上但无 username/password |
| DELETE | /{id} | system:user:delete | 内置用户与自己不能删（40901） |
| PUT | /{id}/password | system:user:reset-password | `{password}`；token_version+1 |
| GET | /options | 🔑 | 启用用户下拉 `[{id, username, nickname}]` |

`UserView = {id, username, nickname, email, phone, avatar, gender, departmentId, departmentName, status, isBuiltin, roleIds:number[], roleNames:string[], lastLoginAt, lastLoginIp, createdAt, updatedAt}`（**绝不返回 password / token_version**）

### 6.3 角色 `/api/roles`

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | / | system:role:list | 分页；`keyword`、`status` → `RoleView[]` |
| GET | /options | 🔑 | 启用角色下拉 `[{id, name, code}]` |
| GET | /{id} | system:role:list | `RoleView` + `menuIds:number[]` |

### 6.4 菜单 `/api/menus`

| 方法 | 路径 | 权限 | 说明 |

## 7. 前端（`web/`，仓库根目录）

对标 mono4ts `packages/web` 的**骨架**，不搬业务组件。

```
web/src/

├── config.ts                    # 读 VITE_APP_TITLE 等

├── components/                  # Permission(按钮级)、DictTag、DictSelect、DepartmentTreeSelect、IconPicker、SearchToolbar、StatusTag、PageContainer
├── layouts/AdminLayout.tsx      # 侧边栏（菜单树渲染）+ 顶栏（面包屑、用户下拉：个人中心/退出）+ 多页签(可关闭，右键关闭其它) + 内容区
└── pages/
    ├── login/LoginPage.tsx
    ├── dashboard/DashboardPage.tsx      # 欢迎页 + 当前用户信息卡片
    ├── profile/ProfilePage.tsx          # 修改资料、修改密码
    ├── forbidden/ForbiddenPage.tsx · not-found/NotFoundPage.tsx
    ├── system/{users/UsersPage, roles/RolesPage, menus/MenusPage, departments/DepartmentsPage, dicts/DictsPage, configs/ConfigsPage}.tsx
```
