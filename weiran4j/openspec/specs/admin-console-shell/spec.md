# admin-console-shell Specification

## Purpose
本能力长期承担后台管理前端的整体外壳职责：统一的侧边菜单、顶部栏、嵌套布局路由，以及基于当前登录账号权限的菜单显隐控制。它是所有后台业务模块页面（角色管理、账号管理、封禁管理及未来陆续加入的其它模块）共同挂载的容器，不包含任何具体业务模块自身的数据交互逻辑。

## Requirements

### Requirement: [FR-001] 后台布局容器

已登录且通过鉴权守卫的用户 **MUST** 在访问后台业务路径时看到统一的布局外壳（侧边菜单 + 顶部栏 + 内容区），业务页面 **MUST** 渲染在该外壳的内容区内，不重复实现导航结构。

#### Scenario: 访问角色管理页面时渲染在统一布局内
- **WHEN** 已登录用户导航到角色管理页面路径
- **THEN** 页面同时渲染出侧边菜单、顶部栏与角色管理列表内容
- **判据**:页面 DOM 中同时存在布局容器的侧边菜单节点与角色管理页面特有的列表容器节点（组件测试断言两者均被挂载）

### Requirement: [FR-002] 菜单按权限点过滤显隐

侧边菜单的每个业务模块入口 **MUST** 绑定一个权限点，当前账号不具备对应权限点时，该菜单项 **MUST NOT** 在侧边菜单中渲染。菜单项的显隐判断 **MUST** 复用已有的 `hasPermission()` 函数，不重新实现权限比对逻辑。

#### Scenario: 不具备角色管理权限的账号看不到角色管理菜单项
- **WHEN** 当前登录账号的 `permissions` 集合不包含 `weiran-system:role.manage`
- **THEN** 侧边菜单中不渲染"角色管理"菜单项
- **判据**:组件测试中，用不含该权限点的账号数据渲染 `AdminLayout`，断言 DOM 中不存在"角色管理"菜单项文本节点

#### Scenario: 前端隐藏不作为唯一安全边界
- **WHEN** 用户绕过前端直接调用角色管理相关 REST 接口，且当前账号不具备对应权限点
- **THEN** 后端接口拒绝该请求，与前端菜单是否显示无关
- **判据**:直接对角色列表接口发起 HTTP 请求（不经过前端菜单），使用不具备 `weiran-system:role.manage` 权限的账号令牌，接口返回 HTTP 403 或对应业务错误码

### Requirement: [FR-003] 顶部栏账号信息与登出

顶部栏 **MUST** 展示当前登录账号的显示名，并提供登出入口；点击登出后 **MUST** 清除本地令牌并跳转回登录页。

#### Scenario: 点击登出后本地令牌被清除
- **WHEN** 用户在顶部栏点击登出按钮
- **THEN** 本地存储的令牌被清除，页面跳转到登录页路径
- **判据**:组件测试中触发登出交互后，断言 `localStorage` 中 `weiran_token` 键已被移除，且路由跳转目标为 `/login`

### Requirement: [FR-004] 嵌套路由结构

后台业务模块的路由 **MUST** 以 `AdminLayout` 为父路由、各业务页面为子路由的嵌套结构组织，新增业务模块页面时 **MUST NOT** 要求修改布局组件本身的实现，只需在路由表中追加子路由项。

#### Scenario: 未登录用户访问后台业务路径被重定向到登录页
- **WHEN** 未登录用户直接访问角色管理页面路径
- **THEN** 请求被 `RequireAuth` 拦截，重定向到登录页
- **判据**:路由测试中，在无本地令牌的状态下渲染应用并导航到角色管理路径，断言最终渲染的是登录页组件而非角色管理页面
